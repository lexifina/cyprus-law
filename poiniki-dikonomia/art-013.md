# Συλλαμβανόμενοι μεταφέρονται σε αστυνομικό σταθμό ή σε τόπο παραλαβής συλλαμβανομένων
13. Όποιος συλλαμβάνεται, είτε με ένταλμα είτε χωρίς ένταλμα, πρέπει να μεταφέρεται με κάθε εύλογη σπουδή σε αστυνομικό σταθμό ή άλλο τόπο παραλαβής συλληφθέντων και, χωρίς καθυστέρηση να πληροφορείται για την κατηγορία εναντίον του.
Σε κάθε τέτοιο πρόσωπο, ενώ τελεί υπό κράτηση, πρέπει να παρέχονται εύλογες διευκολύνσεις για να εξασφαλίσει νομική συμβουλή για να προβεί σε διαβήματα για εξασφάλιση απόλυσης με εγγύηση και διαφορετικά για να προβεί σε διευθετήσεις για την υπεράσπιση ή απόλυση του.
